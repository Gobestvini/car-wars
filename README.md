# Car Stars / Driving Lab

Лёгкий прототип езды на **Three.js + cannon-es**, без React, WASM и игровых фреймворков. Компактный процедурный район со связной сеткой улиц, зданиями, ориентирами и шестью машинами трафика. Карта одинакова при каждом запуске; на её краю стоит физически замкнутая граница.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

На этом компьютере можно запустить `powershell -ExecutionPolicy Bypass -File .\start.ps1`: скрипт использует установленный Node/npm или встроенный Node/pnpm из Codex.

```sh
npm install
npm run dev
```

Открой адрес, показанный Vite (обычно http://localhost:5173). Чтобы открыть на телефоне, подключи его к той же Wi-Fi сети и используй IP компьютера и порт 5173. Сервер слушает `0.0.0.0`; Windows может запросить доступ через брандмауэр.

Также поддерживается `pnpm install && pnpm dev`; lockfile включён.

Управление задачами через Telegram на этом компьютере: [инструкция](docs/TELEGRAM.md).

```sh
npm test
npm run build
npm run preview
```

`dist/` можно разместить на статическом хостинге. Модель и текстура включены в проект; после сборки шрифту разрешён необязательный запрос Google Fonts, при отсутствии сети используется Arial.

## Публикация в интернете

В репозитории настроена автоматическая публикация в бесплатный GitHub Pages. Она подходит для одиночной игры на телефоне: после публикации сайт доступен по HTTPS из любой сети. Игровой сервер и платный тариф не нужны; многопользовательский режим этим способом не добавляется.

1. Помести проект в публичный GitHub-репозиторий (GitHub Pages доступен для публичных репозиториев на бесплатном тарифе).
2. В репозитории открой **Settings → Pages** и выбери **Build and deployment → Source → GitHub Actions**.
3. Отправь код в ветку `main` или `master`. Workflow `.github/workflows/publish.yml` установит зависимости по lockfile, соберёт игру и опубликует её.
4. Открой **Actions → Publish game to GitHub Pages**. Когда запуск завершится успешно, адрес игры появится в окружении `github-pages` в задании публикации. Обычно адрес имеет вид `https://<имя-владельца>.github.io/<имя-репозитория>/`.

Для последующих обновлений достаточно отправить изменения в `main` или `master`; повторную публикацию выполнит GitHub Actions. Первый запуск можно начать вручную через **Actions → Publish game to GitHub Pages → Run workflow**. Настройка Vite использует относительные пути, поэтому приложение и модель загружаются также по адресу проекта с подкаталогом.

## Управление

- Коснись площадки пальцем или левой кнопкой мыши: **центр плавающего джойстика фиксируется в точке первого касания**. Тяни от центра в нужном направлении экрана; отклонение регулирует скорость. Центр не перемещается вместе с машиной. Радиус — 64 px, мёртвая зона — 8 px. Верни палец в центр или отпусти для торможения.
- Потяни джойстик против направления носа машины — она сначала затормозит, затем поедет задом. Потяни вперёд — вернётся к переднему ходу. Около поперечного направления действует гистерезис, чтобы передачи не переключались от небольшого движения пальца. При отпускании машина плавно катится по инерции.
- `W / ↑` — газ; `S / ↓` — тормоз, затем задний ход; `A / D` или стрелки — руль.
- `Space` — ручник задней оси. `R` или «Заново» — вернуть машину, очистить следы/повреждения и восстановить трафик.
- Шестерёнка — жёсткость подвески, сцепление, мощность, следы шин.

Город запускается с дорогами шириной 15 м; ширину (12–30 м) и количество машин можно менять в настройках. В URL добавь `#debug`, чтобы открыть инструменты разработчика и сохранять текущие настройки как начальные для этого браузера.

## Физика

`src/vehicle.js` отделён от графики, работает в метрах, килограммах и секундах. Шаг — **120 Гц**, с аккумулятором и интерполяцией кузова. Слишком длинная пауза ограничивается; скрытая вкладка приостанавливает симуляцию.

- Динамическое твёрдое тело массой 1600 кг, смещённая геометрия относительно центра масс.
- Четыре луча подвески, индивидуальная нагрузка, пружины, разное демпфирование сжатия и отбоя, слабые стабилизаторы.
- Силы шин прикладываются у поверхности земли: перенос веса, крены и продольная раскачка возникают в динамике кузова.
- Нелинейная зависимость сцепления от угла увода, плавное падение после пика и круг трения, объединяющий боковую силу с разгоном и торможением.
- Более аркадная настройка: полный привод со смещением тяги назад, примерно 100 км/ч за 3 секунды, более отзывчивый руль, сцепление до 1.8 и заметный накат. Сохранены крен, упрощённые пять тяговых диапазонов, ручной занос и сопротивление воздуха.
- Колёса диаметром 0.9 м; физический радиус соответствует модели. Позиции, поворот и вращение колёс интерполируются в том же шаге, что и кузов, чтобы устранить дрожание на скорости.
- Ручник снижает сцепление и тормозит задние колёса. Шины рисуют следы шириной 0.29 м при срыве сцепления; кольцевой буфер ограничен 6000 сегментами (около 50 с при темпе 120 сегментов/с, без учёта завершающих сегментов fade). Колея сужена до 1.54 м, ширина шины — 0.3 м, чтобы колёса помещались в кузов.

Это **приближение характера GTA IV**, а не воспроизведение закрытого кода Rockstar. Сильное попадание рядом с колесом может оторвать его: колесо продолжает физически двигаться, а машина едет на оставшихся колёсах до сброса. Точная коробка передач/дифференциал и совпадение с конкретной машиной GTA не реализованы. Подробнее о найденных источниках и ограничениях: [RESEARCH.md](RESEARCH.md).

## Город и трафик

Район строится локально из фиксированного seed `20261005`: 34 здания нескольких цветов и высот, три силуэтных ориентира, пересекающиеся дороги и замкнутый периметр. Здания и край карты имеют статические коллизии; дорога остаётся проезжаемой, а обычный сброс машины не пересоздаёт карту. Шесть упрощённых автомобилей движутся по замкнутому маршруту внутри района с ограниченной скоростью. Они визуальные и не участвуют в физике или столкновениях.

## Повреждения и визуальные эффекты

Удар кузова о физическое препятствие создаёт локальную вмятину в модели. События измеряются по нормальной скорости сближения с учётом вращения: до 3 м/с урона нет, затем он плавно растёт и насыщается при 20 м/с. Вмятины накапливаются и ограничены смещением 0.30 м; урон выше 50% снижает тягу, а при 100% двигатель отключается. От 15% появляется серый дым из капота, от 45% дым густеет и темнеет, от 75% добавляются пламя и искры. При полном разрушении после 0.6 с горения происходит один визуальный взрыв со вспышкой и затухающим облаком. Взрыв не наносит дополнительного физического урона. `R`/«Вернуть машину» восстанавливает кузов, колёса и полностью очищает эффекты.

Для проверки столкновений открыть `http://localhost:5173/?damageTest=1#debug`. Площадка содержит физически соответствующие переднее, боковое и заднее препятствия. Также поддерживаются варианты `?damageTest=front`, `?damageTest=side`, `?damageTest=rear` и `?damageTest=wheel`; последний запускает воспроизводимый боковой удар около 18 м/с в область переднего колеса. Для просмотра стадий доступен `?damagePreview=0.85#debug` (значение 0..1); этот preset применяется один раз после загрузки модели и очищается обычным сбросом. Отрыв дверей/капота и разбитые стёкла не реализованы.

В версии 1.1.0 на каждом регулируемом перекрёстке постоянно присутствуют четыре комплекта светофоров. Активный цвет ярко подсвечивает входящий подход мягким пятном на дороге. Дорожные штрихи и стоп-линии принимают тени. Здания начинают плавно становиться прозрачными при приближении машины к фасаду ближе 6 м, достигают прозрачности 22% около 2 м и восстанавливаются после отъезда; коллизии сохраняются.

## Модель

Седан из [Kenney Car Kit](https://kenney.nl/assets/car-kit), **CC0**, 3.1. Отдельные колёса вращаются и следуют за подвеской. Пропорции кузова адаптированы для прототипа. Лицензия — `public/models/LICENSE.txt`. Ресурсы GTA не включены.

## Проверки

`npm test` проверяет равновесие подвески, разгон, поворот/крен, торможение, задний ход, сброс, согласованность шагов 60/120 Гц и устойчивость крайних настроек. Результаты визуальной проверки описаны в `VERIFICATION.md`.

## База знаний Bruno Simon

[Начать с базы знаний](docs/knowledge/README.md): каталог двух курсов и 87 уроков, 90 публичных видео и дополнительные эфиры/Short, практические правила с первичными источниками и карта применённых изменений. Статусы отличают прочитанный код, разобранные разделы субтитров и материал, который пока только внесён в каталог.

После исследования добавлены согласованное следование камеры за интерполированной машиной, ограничение догоняющих шагов физики, общие ресурсы протекторов, мягкие исчезающие следы, загрузка с повтором и предварительной компиляцией. В настройках доступны высокая и лёгкая графика. Для диагностики открыть `http://localhost:5173/#debug`: FPS, время CPU, физика, draw calls и треугольники. Измеренное время CPU не является временем GPU.
