# Menu fonts

Self-hosted official Google Fonts files, downloaded 2026-10-09:

- Lilita One Regular: https://raw.githubusercontent.com/google/fonts/main/ofl/lilitaone/LilitaOne-Regular.ttf
- Roboto variable: https://raw.githubusercontent.com/google/fonts/main/ofl/roboto/Roboto%5Bwdth,wght%5D.ttf

Both are distributed under SIL Open Font License 1.1; the complete respective
licenses are included as `LilitaOne-OFL.txt` and `Roboto-OFL.txt`.
The sculpted logo and role headings are approved raster artwork; PLAY remains
native text in Lilita One, and descriptions use Roboto Black (weight 900).
