# CarWars: работа с задачами

При запросе на подготовку задания для другой модели используй `$create-task`, если навык доступен, и соглашения из `docs/tasks/README.md`. Подготовка задачи сама по себе не означает выполнение описанных изменений.

При выполнении задачи из `docs/tasks/` прочитай её целиком и следуй её области изменений и критериям готовности. Проверь актуальность указанных файлов и поведения перед правками. Если задача устарела или противоречит текущему запросу пользователя, укажи расхождение и руководствуйся текущим запросом.

Обновляй статус и отчёт в файле задачи. Не объявляй задачу выполненной без требуемых проверок; если проверка недоступна, явно укажи это. Общие соглашения и карта проекта находятся в `docs/tasks/README.md`.
