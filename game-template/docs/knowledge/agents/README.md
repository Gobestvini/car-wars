# Проверяемая память

`pnpm context -- "тема"` читает memory.json, выбирает до восьми актуальных записей и ограничивает подсказки 6000 символами плюс краткая инструкция. Каждая запись привязана к SHA-256 исходников. После изменения/удаления источника она исключается. Новая игра начинает с пустой памяти.

`recordKnowledge(cwd, { taskPath, summary, checked })` в tools/telegram/knowledge.js записывает короткий итог только при checked.ok. Telegram runner вызывает её после тестов и сборки. Итог помечается как отчёт исполнителя; это не доказательство всех ручных критериев. Вручную добавляй только проверенные факты с актуальными source hashes. Память не заменяет чтение задачи и нужного кода.
