# База знаний для новой игры

Переносимые инженерные выводы из CarWars и справочник по первичным материалам. Обновлено 8 октября 2026. Документы помогают выбирать решения; реализованные возможности новой игры проверяй по её коду. Сейчас каркас использует Canvas 2D: Three.js, физический мир, NPC и загрузчик ещё не подключены.

## Как сохранять новые знания

- Общий приём и его ограничения добавляй в соответствующий справочник; для API указывай первичный источник и версию.
- Принятое архитектурное решение описывай кратко: проблема → варианты → выбор → владельцы → инварианты → проверка. Пример формата есть в [архитектуре](game-architecture.md).
- Исследование нового проекта записывай в [RESEARCH](../RESEARCH.md). Наблюдение по исходникам, рекомендация и измеренный результат имеют разные статусы.
- Результат задачи и source hashes записывай в `agents/memory.json` по его контракту. Общий совет не становится проверенным фактом проекта после успешной сборки.

Память новой игры остаётся пустой. Частоты физики, размеры теней, лимиты NPC и результаты замеров CarWars не являются её настройками или доказательством её производительности.
