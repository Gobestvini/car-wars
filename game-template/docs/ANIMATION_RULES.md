# Движение и обратная связь

Симуляция определяет игровой результат; графика отображает previous/current через alpha. При reset обе позы сбрасываются вместе. Камера использует отображаемую позу. Для углов выбирай кратчайшую дугу, для 3D-ориентации quaternion interpolation. Декоративное сглаживание не изменяет collider, hit timing и задержку ввода.

У свойства один владелец transition. Повторное действие продолжает текущее значение, а отмена/reset очищает callbacks и таймеры. Не создавай tween каждый кадр. Предпочтение reduced motion убирает декоративный shake/смещение/масштаб, сохраняя точность игрового состояния. Bounce, flash и camera shake выбираются по концепции игры и настройкам пользователя; их наличие само по себе не означает polish.

Проверяй быстрое повторное нажатие, обратный переход, закрытие панели, pause/reset и разные FPS. Разделение логики и изображения предотвращает «красивую», но запоздалую обратную связь.
