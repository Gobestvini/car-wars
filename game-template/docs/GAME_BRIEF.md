# Паспорт новой игры

Заполни до выбора движка и крупных изменений. Сейчас это пустой шаблон; значения ниже требуют решения для новой игры.

- Игрок и основное действие: не определены.
- Цель, победа/поражение, длительность сессии: не определены.
- Первый играбельный срез: одно действие → обратная связь → результат → перезапуск.
- Целевые устройства, браузеры/платформы, ввод: не определены.
- Визуальная и звуковая концепция, референсы: не определены.
- Ограничения и то, что не входит в первый срез: не определены.
- Движок: начать с текущего Canvas либо выбрать по требованиям; не переносить старый стек автоматически.

## Измеримые бюджеты

Запиши целевое устройство и одинаковый сценарий до/после. Выбери целевую частоту: например 60 FPS даёт 16.7 мс на кадр, 30 FPS — 33.3 мс. Это арифметика бюджета, а не измерение мощности устройства.

| Метрика | Цель новой игры | Как измерять |
| --- | --- | --- |
| p95 времени кадра | определить | устройство, версия, прогрев, длительность |
| CPU симуляции / render | определить | отдельные замеры; CPU render не GPU |
| Загрузка / вес | определить | cold load, сеть, compressed transfer |
| Память и ресурсы | определить | baseline и серия reset/смен сцен |
| Задержка ввода | определить | реальное устройство, повторяемое действие |

Не заполняй FPS, RAM и число объектов произвольными «универсальными» лимитами.
