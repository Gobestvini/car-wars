Прочитай `docs/GAME_BRIEF.md` и релевантный раздел `docs/knowledge/playbook.md`. По `docs/knowledge/README.md` выбери дополнительные материалы: `game-architecture.md` для владельцев, физики и NPC, `threejs.md` для renderer/материалов/шейдеров, `debug-performance.md` для дефектов и замеров, `assets-and-ui.md` для контента и управления. Не читай всю базу для каждой правки. Проверяй источники и установленную версию API по `sources.md`; рекомендации не означают уже реализованные возможности.

Не навязывай движок, жанр или численные бюджеты до требований игры. Определи наблюдаемый сценарий, сделай маленький играбельный срез, проверь reset/pause/focus и подходящие частоты кадров. Производительность сравнивай при одинаковом сценарии и устройстве. Для ресурсов проверь владельца и освобождение. Отчёт различает unit/build, browser surrogate, реальное устройство и ручное ощущение управления. Сначала игра должна быть понятной и отзывчивой; оптимизацию подтверждай замерами.
