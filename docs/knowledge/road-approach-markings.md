# Разметка перед стоп-линиями

- Признак: пунктир доходит до перекрёстка без сплошного участка; стоп-линия слишком тонкая по референсу.
- Причина: `createRoadMarkings` возвращал только центры одинаковых штрихов, а `city-scene` задавал всем длину 2,2 м.
- Способ: элементы содержат `kind`/`length`; один InstancedMesh использует единичную плоскость и масштаб длины. На регулируемых концах roadSegments центральная линия сплошная на 12 м до общей плоскости `getStopLineLayout`. Интервалы ограничиваются доступным участком и объединяются; штрихи обрезаются на их границах. Меняется визуальная толщина стоп-линии (0,6 м), но не её плоскость для AI/нарушений. Ширина центральной линии остаётся 0,16 м.
- Проверка 2026-10-18: 23 целевых node:test прошли; Edge software WebGL, 16 комбинаций ширины/viewport/качества и повторная перестройка, без page/shader errors. Скриншоты обеих осей и низкого угла просмотрены. Повторный полный suite 357/357 + build; независимый QA принял задачу и дополнительно проверил 300 городов (20853 отрезка), реальные матрицы и dispose. Полный отчёт разработки/QA: [TASK-0106](../tasks/TASK-0106-stop-line-approach-markings.md).
- Ограничения: геометрия текущей ортогональной сети, подходы степени 4, одна полоса в каждом направлении; нормативное соответствие и физический телефон не проверялись. Legacy grid API сохранён. Скриншоты в игнорируемом `tools/screenshots/stop-approaches-*`; браузерный runner запускается с `PLAYWRIGHT_MODULE` и `CARWARS_BASE_URL`, если модуля/сервера нет по default.

Не переносить старое фиксированное число 144 стоп-линий из браузерного теста на процедурные города: ожидаемое число выводится из числа узлов степени 4 и четырёх подходов.
