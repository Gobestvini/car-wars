## Отдельный allocation sampling

`allocation-stable/desktop-high-300-1.json`: отдельные60сек, sampling32KB с учётом collected objects. Это статистическая оценка суммарного созданного объёма, **не retained heap и не точное число выделенных байтов**; profiler overhead не сравнивается с CPU timing матрицы. Оценка12.31GB распределена по стекам: `footprintsOverlap` минимум3.56GB, `segmentHitsRect` минимум3.47GB, замыкания/массивы проверки arrest corridor ещё1.14GB; controller .50GB, Cannon separating axes .39GB, pickup visuals .22GB, building segment tests .16GB. Все стеки и sampled sizes сохранены. Самые крупные источники — повторное создание SAT axes/corners и массивов для slab intersection; первыми кандидатами №82 становятся эквивалентные scalar/scratch вычисления этих операций. Оптимизация только render submission главного CPU bottleneck не устранит.

Спокойный маршрут не породил tireSmoke (active0); это ограничение основной матрицы. Дополнительно выполнены6full60s runs в `effects-baseline/`: keyboard W→turn+Space, reset каждые12сек; затем20переключений free camera для production fade. Каждый сценарий повторён3раза. Все завершились без errors/overwritten, GPU timer available;3502/3471/3582frames skid и3532/3507/3505fade. TireSmoke highWater/max active10 во всех3skid, damage activeSmoke69/70/70. Fade active2 и proxyCreated20 во всех3повторах, damageSmoke70/70/72. Это отдельные искусственно выбранные позиции/клавиши, не естественный спокойный маршрут; физика/эмиттеры/fade выполняются production кодом. Production Math.random сохранён, поэтому плотность damageSmoke имеет ожидаемый разброс; исходники всех6одинаковы, SHA-256 src-only21600b167027e5e71452809668b349851a1d57dd4dffd917dd9c24d4c39f1351. Launcher назначил affinity1 родительскому процессу, browser наследует её; в supplementary raw mask объявлена, полный CDP/OS inventory masks содержится в основной матрице, не заявляется отдельная повторная OS проверка этого helper. Для повторения: PLAYWRIGHT_MODULE, затем Start-Process node tools/scene-effects-profile.cjs с ProcessorAffinity1 и ожиданием окончания, как launcher основной серии; helper читает CARWARS_BASE_URL/SCENE_PROFILE_OUT.

После baseline collector получил флаг DrivingOnly для отдельной повторной проверки77 без искусственного wanted/damage trigger. Эта опция по умолчанию false, algorithms production не меняются; sourceHash collector после добавления флага отличается, исходный18run dataset сохраняется и не перезаписывается. Следующие сравнения фиксируют новый collector/protocol вместе с отдельным src-only hash, чтобы не спутать изменение измерительного инструмента с изменением игры.
