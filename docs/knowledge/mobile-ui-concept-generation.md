# Мобильные концепты интерфейса Car Stars

Источник: запрос пользователя 2026-10-24, уточнение «для мобильных платформ»; локальные генерации встроенным ImageGen. Проверка: визуальная, декодирование PNG и SHA-256, без запуска игрового UI.

- Проблема: при независимой генерации второго состояния города модель поменяла энергию на звёзды, цены карт и автомобиль перехвата на вертолёт.
- Причина: общий референс меню удерживает стиль, но не фиксирует содержание игровой панели.
- Рабочий способ в этом наборе: редактировать уже полученный основной экран города, явно зафиксировав пять карточек, значки энергии и цены; другой кадр использовать только как пример ghost/targeting.
- Подтверждение 2026-10-24: в итоговых 07/08 совпадают панель и цены 2/3/2/2/3, INTERCEPT содержит машину. Старый ошибочный вариант не включён в набор.
- Ограничения: приём не гарантирует правильную карту, endpoint placement, safe area, touch targets или баланс. Это проверенный результат конкретной генерации, а не тест работающего интерфейса.

Набор: [20 мобильных экранов](../art/concepts/2026-10-24-mobile/README.md). Перед похожей работой учитывать актуальный [city-hunt дизайн](city-hunt-mode-design.md): один город, три гонщика, пять карт. Старый шестикадровый Figma-обзор 2026-10-09 полезен для стиля, но его одиночный patrol-command экран не описывает новый режим.
