# NPC после тротуарного контакта — 2026-10-19

Признак → нормально ориентированный NPC с целыми колёсами после слабого удара перестаёт двигаться, хотя можно безопасно вернуться на дорогу. Причина → целый предмет остаётся реальным препятствием, controller продолжает газовать; online нет манёвра, offline пересчёт маршрута сам по себе не освобождает кузов. TASK-0108 устранила блокировку сбитым предметом, но сохраняет пороги, поэтому слабый контакт требует отдельного выхода.

Рабочий способ → общий `traffic-prop-recovery.js`, только после реального контакта: торможение, проверка соседей/домов/целых props по всему коридору, ограниченный задний ход и возвращение на текущий путь. Начально перекрывающий предмет допускается только на отделяющемся заднем ходе; на переднем участке все препятствия учитываются. Повторная проверка на каждом решении AI. Нет безопасного коридора → ожидание с blocker; красный/занятый выход/чужая резервация не обходятся. Тело и колёса остаются физическими; LOD не завершает активный манёвр скачком.

Отдельный цикл очереди → NPC позади лидера получает ещё не въехавшую резервацию и затем ждёт лидера, который ждёт этого же владельца. Проверенный способ → приоритет головы полосы и удаление такой неиспользованной резервации; занятая машина сохраняет владение до выезда. Общий online AI остаётся упрощённым, законная пробка сама по себе не исправляется исчезновением NPC.

Проверка → `before-after.json` использует сохранённые до 0109 исходники, но одинаковую новую физику 0108. Seed=42, урна `bin:74`, 2 м/с, ребро `75:-75 → 125:-75`: до — ~0.27 м за 10 с в обоих режимах; после — online 25.22 м, offline 33.64 м. Сохранены позы, quaternion, скорости, управление и причины, без копирования исходных чужих правок в артефакт.

`soak.json` → 300 с с 102 NPC/3 игроками и двумя начальными реальными ударами, индивидуальные метрики каждого NPC и секундные трассы пострадавших. Законные длинные ожидания имеют причины и отдельные `longWaitEvidence`. Таймер свободного проезда сбрасывается при реальном ограничении; 10 секунд красного плюс 0.1 секунды начала разгона нельзя назвать 10.1 секунды необъяснённой остановки.

`browser/report.json` и PNG → локальные hosted/Vite и Edge WebGL. В online фиксируется авторитетный кадр у каждого из трёх клиентов. Для одинакового simulation age серверный clock удерживается, NPC отображаются из серверного buffer без дополнительного локального prediction; собственная машина сохраняет prediction. Это проверка AI/репликации и кадров, не сетевой задержки. Каждый независимый online сценарий начинает свежую карту/популяцию с возрастающими tick/generation. После настоящего контакта позы не назначаются. Offline использует тот же игровой traffic/prop runtime, high/low × 1440×900/390×844.

Ограничения → эмуляция мобильного viewport не подтверждает физический телефон. Нет новой механики переворота/респавна и публичной выкладки. Сильные разрушения используют проверенную семантику 0108; неизменность порогов проверяется её отдельными тестами. Полный итог и независимое решение — в TASK-0109, разделах 10–11.

Проверки исполнителя → полный текущий root suite 402/402 и build 1.64 с, fingerprint `6e628113099df3a9a40459114347b222087e5befc116e315cc2254b65d8e02e8`. Дополнительно изолированное дерево будущего коммита поверх исходного HEAD, без чужих staged/unstaged правок: 58/58 профильных тестов, build 1.88 с и полный `npm test` 432/432 (155.4 с). Разница числа тестов вызвана чужой незавершённой миграцией tooling, чьи удаления не входят в этот коммит. Полные логи не копируются в базу знаний; независимый QA сохраняет собственные доказательства в `docs/knowledge/qa-0109/`.
