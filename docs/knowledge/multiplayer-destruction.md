# Онлайн: кузов, тротуарные объекты и джойстик

2026-10-18. Признаки: после переноса в online пропали вмятины и сносимые
декорации, ручка джойстика оставалась в центре при работающем управлении.
Причина: отдельный online renderer подключал только скаляр damage/дым, создавал
город без StreetPropPhysics и не обновлял transform ручки в pointermove.

Рабочий способ:

- Сервер хранит до 32 локальных ударов кузова на поколение машины, как офлайн
  CarDeformation. Полные motion frames передают историю, поэтому поздний вход
  видит те же вмятины. Смена generation очищает только кузов этой машины.
  Геометрия клонируется для каждого игрока; повторные кадры не повторяют удар.
- Подписанная карта v3 включает серверный manifest фонарей, урн, скамеек,
  светофоров и деревьев. Проверяется точное совпадение с placement/render IDs.
  Общий StreetPropPhysics считает удары и обломки на сервере и в prediction.
  Каждый полный кадр несёт состояния detached/removed; intact подразумевается.
  Это ограниченный размер состояния, а не бесконечный журнал событий.
- Rewind восстанавливает p/q/v/av, возраст обломка и жизненный цикл. После пяти
  секунд обломок исчезает, removed ID сохраняется до закрытия комнаты. Визуальный
  registry перемещает исходные instance slots, включая кроны деревьев, и гасит
  разрушенный светофор. Replay не пишет повреждения кузова на клиенте.
- Ручка использует существующие knobX/knobY joystickVector. Новый жест центрирует
  ручку; второй палец/правая кнопка не захватывают управление, чужой pointerup
  не сбрасывает активный жест.

Проверено локально: 74 целевых теста (включая 7 новых), сборка Vite; отдельно
настоящие три SDK-клиента: удары, поздний вход с вмятинами/сбитой урной, исчезновение
обломка, независимый respawn, обрыв и автоматическое переподключение. Тест reconnect
ждёт минимальные 5 секунд существования клиентского соединения, требуемые SDK.

Три настоящие 3D-вкладки в операторской localhost-фикстуре показали одинаковые
11/2/0 ударов и 2436/894/0 изменённых вершин трёх кузовов, два уничтоженных объекта,
577 зарегистрированных объектов, frame p95 около 16.8 ms. Ошибок console error
нет. Реальный drag (100, -60) px дал transform ручки (54.8796, -32.9277) px,
то есть ограниченный существующим радиусом 64 px. Это проверка мышью в desktop
браузере; физический сенсорный телефон не проверен.

Доказательства: [browser-local.json](multiplayer/2026-10-18-destruction/browser-local.json),
[кадр с вмятиной](multiplayer/2026-10-18-destruction/three-clients-dents.png).
Операторская фикстура `browser-destruction-probe.js` слушает только localhost и не
подключается production entrypoint; публичного API перестановки машин нет.

Ограничения: сервер остаётся preview-миром; полиция/розыск/аптечки ещё не перенесены.
Дома не разрушаются. Постоянного сохранения комнаты после рестарта нет.
Физический replay обломков проверен с допуском 2.5 cm/0.2 m/s на коротком
интервале: смена порядка контактов Cannon при пересоздании тел может давать небольшие
расхождения, которые исправляет сервер. Не выдавать это за побитовую детерминированность.
