## Проверенный приём и ограничения

Признак → soak зелёный при очень долгих остановках. Причина → любой текст `reason` сам по себе не доказывает законное ожидание. Рабочий способ → независимо сопоставлять reason с геометрией/скоростью реального blocker, фазой, владельцем и цепочкой зависимостей; отдельно снимать внешний blocker и измерять начало движения/освобождение резервации. Подтверждение 2026-10-19 → геометрический аудит 300 с и отдельный clearance выше. Ограничение → безопасная плотная очередь может законно ждать дольше 10 с; окно свободного проезда начинается после исчезновения всех действующих ограничений.

Browser clock удерживался между шагами для сопоставимых кадров. NPC показаны из authoritative buffer без локального prediction; собственная машина сохраняет prediction. Это подтверждение физики/AI/репликации, не измерение задержки сети или производительности. Мобильный viewport/DPR=1 — эмуляция; физический телефон и публичная выкладка не проверялись. Покрытие фиксированного seed и выбранных маршрутов не является доказательством для всех случайных городов.
