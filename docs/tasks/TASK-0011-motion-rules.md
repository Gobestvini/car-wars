## 4. Требуемое поведение

Документ покрывает каждый тип: камера и зум; кузов/колёса/NPC; opacity домов; следы; панели/кнопки/HUD; повреждения; загрузка/reset/пауза. Для каждого указать источник времени, длительность/ставку, easing, прерывание и reduced-motion. Определить исключения: столкновения, reset, физический шаг и прямой ввод должны оставаться точными и отзывчивыми. Не сглаживать команды джойстика ради украшения.
Базовые правила автора: независимость от FPS через dt, экспонента 1-exp(-rate*dt) для следования, ease-out без bounce/overshoot для UI, короткая реакция кнопок 100–160 мс, панели 180–240 мс opacity+translate 6–8px, показатели HUD 120–200 мс. При смене цели продолжать из текущего значения, не запускать новую анимацию из нуля. Один владелец свойства, без конкурентных tween и накопления обработчиков. Углы по кратчайшему пути, quaternion slerp; hidden/pause не вызывает догоняющего рывка.
Практическое применение: добавить render(alpha) для трафика со снимками предыдущего/текущего состояния. Скруглить маршрут вблизи углов в пределах дорожного коридора, чтобы положение и heading согласованно менялись; не только крутить кузов при прямоугольном скачке траектории. Сохранить число NPC, направление, speed в м/с, reset/dispose. Если TASK-0009 уже выполнена, использовать её размеры; иначе коридор шириной 10 м.
Добавить плавное открытие/закрытие settings и нейтральную короткую реакцию кнопок. Во время closing нельзя оставлять невидимый перехватывающий ввод слой; hidden ставить по завершении, отменять closing при быстром повторном открытии. Скрытая панель не доступна Tab; закрытие возвращает фокус кнопке. loading/status не прыгают по экрану.
prefers-reduced-motion: убрать декоративные смещения и масштаб, панель менять почти сразу; оставить нужную интерполяцию физики и спокойную камеру. Добавленное автором правило обратной связи: успех настройки — мягкое изменение цвета/opacity, без постоянного пульса, shake камеры, flash и крупного прыжка машины. Библиотеки tween не добавлять.
