## 4. Требуемое поведение

- В режиме debug добавить штатный переключатель «Камера: Машина / Свободная», скорость перемещения и кнопку возврата к машине. Вне debug текущий UI не расширять.
- Предложение автора для свободного осмотра: OrbitControls rotate/pan/zoom; desktop drag/right-drag/wheel, WASD перемещение точки обзора, Q/E высота. Touch: один палец вращение, два pan/pinch; все жесты отделены от driving joystick.
- При входе очистить keys/pointer/жест пончиков, зафиксировать input игрока в безопасное нейтральное торможение; физика/трафик/светофоры продолжаются. WASD свободной камеры не даёт газ машине; UI-фокус не перехватывается fly-controls.
- Инициализация обзора из текущего положения без неожиданного скачка; pan/высота позволяют осмотреть всю площадь420×420 м и крайние кварталы. Поднять far plane только в свободном режиме настолько, чтобы видеть весь город; восстановить исходный far при выходе.
- Сохранять цель/позицию свободного обзора в пределах текущей сессии; ограничить высоту/zoom и вертикальный наклон против прохождения под землю/нечисловых значений. Скорость в м/с, dt ограниченный, одинаковая при разных FPS.
- На выходе отключить controls/listeners, сбросить input, сразу восстановить updateCamera и фиксированный игровой угол; игрок в кадре, новое касание работает без удержанного газа.
- resize, quality, reset, rebuild и hidden tab не ломают режим. При free обзоре тени считают coverage по реальной камере; player occlusion не делает далёкие здания бессмысленно прозрачными.
- Добавить read-only mode/target в carLab.camera; не добавлять подсказки/лендинг или вторую панель.
