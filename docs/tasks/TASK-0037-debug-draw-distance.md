## 4. Требуемое поведение

- Нативный slider+number input в существующем debug-разделе, label «Дальность, м». Предложение автора: диапазон100–1000 м, шаг10. Значение относится к глубине camera far plane в мировых метрах, а не радиусу физической активности NPC.
- Хранить значения для двух режимов, предлагаемые ключи drawDistanceFollow и drawDistanceFree; исходные200/600 м. Единственный видимый контрол показывает значение текущего режима, при смене mode переключает binding/значение с pane.refresh, без ложного change loop.
- При изменении применить camera.far и camera.updateProjectionMatrix, затем согласовать scene.fog. Предложение автора для debug-режима: fog.near=0.5*distance, fog.far=0.95*distance, чтобы покрытие мягко исчезало до clipping. Цвет, background и тип тумана сохранить. Допустима равноценная формула с записанным визуальным обоснованием; фиксированный fog260 не должен скрывать расширенную дальность.
- Обе настройки именованные и валидируются: конечное число, диапазон/шаг; повреждённое значение получает fallback соответствующего режима. UI не показывает NaN или сохранённое неподдерживаемое число. near остаётся0.1; far всегда больше near.
- В debug изменение видно без reload/rebuild; setCameraMode использует выбранное значение режима, не безусловные200/600. Reset машины, quality switch, resize и rebuild не сбрасывают дальность.
- Обычный URL не получает новый контрол. При отсутствии saved profile и debug сохранить прежний camera/fog200/100/260. Если профиль TASK-0031 уже реализован, сохранённое follow значение может применяться и в обычном URL согласно семантике профиля; saved free применяется при включении free, cameraMode не сохранять.
- Если TASK-0031 уже реализована, добавить оба ключа в versioned whitelist/validation/load/save и очистку заводских дефолтов. Если она ещё не реализована, ограничиться текущей сессией; существующее задание0031 содержит условие последующей интеграции. Не создавать вторую независимую систему localStorage.
- Изменение дальности не пересоздаёт meshes/bodies/materials и не меняет выбранное count. Дальний невидимый трафик продолжает логическое движение, близкие NPC остаются физическими за пределами кадра.
- При минимуме follow автомобиль целиком видим даже на максимальном speed zoom; при максимуме free город виден настолько далеко, насколько позволяет позиция/угол камеры. Если далеко нет объектов, нельзя обещать генерацию дополнительного города.
- Поддерживать стабильные тени и отсутствие новых конфликтов глубины. Камера фрустума для NPC и shadow coverage обновляются после изменения projection; sun.shadow.camera.far не является draw distance.
- Добавить carLab diagnostics эффективного camera.far и fog near/far для проверки; не добавлять постоянно видимый HUD.
