## 4. Требуемое поведение

Вход интенсивности — начисленный `wanted.snapshot().level`, не pendingStar. Передавать `wantedLevel` в копии context; выделить чистое получение профиля, не дублировать константы между main/runtime.

Стартовый баланс автора (скорость — м/с; прогноз — секунды; дистанция ram — метры):

| Звёзды | Дальний предел скорости | Упреждение | Намеренный ram / maintain-block |
| --- | --- | --- | --- |
| 0 | 0 | 0 | выключены, idle |
| 1 | 22 | 0.15 | выключены, следование |
| 2 | 28 | 0.25 | выключены, быстрое следование |
| 3 | 34 | 0.35 | ram ≤6 м; блокирование разрешено |
| 4 | 40 | 0.45 | ram ≤8 м; блокирование разрешено |
| 5 | 45 | 0.50 | ram ≤10 м; блокирование разрешено |
| 6 | 50 | 0.55 | ram ≤12 м; блокирование разрешено |

Это пределы желаемой скорости AI, не гарантия фактической скорости. Сохранить ближнее торможение/contactLimit и безопасность препятствий. При 1–2 звёздах следовать с целевой дистанцией минимум 6 м и торможением вместо намеренного въезда/удержания контакта; случайные физические столкновения возможны. При 3–6 сохранить контактное сближение в пределах профиля.

Применять новый профиль на ближайшем AI update без пересоздания контроллера/машин, сброса recovery и прогресса ареста. При level 0 или arrested — прежний idle с тормозом. PendingStar при level N не включает N+1; предупреждение при level 0 не запускает погоню.

Нормализация: дробные значения округлять вниз, конечные ограничивать 0–6; NaN/Infinity/отсутствующий уровень трактовать как 0. Wrapper всегда передаёт явное значение; обновить прямые тестовые вызовы policy. Диагностика сообщает применённый уровень/профиль и желаемую скорость для сравнения даже при насыщении throttle.
