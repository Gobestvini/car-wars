## 4. Требуемое поведение

- Конфигурация явно различает ширину тротуара, отступ дома и ширину/глубину основания. Не считать весь пустой участок квартала тротуаром. Вынести текущие связанные константы генерации в один экспортированный объект с документированными единицами.
- Предложение автора для default20: sidewalkWidth=2 м, диапазоны footprintWidth/Depth=10–12 м вместо 4.4–5.2; четырёхдомовая раскладка с междомовым зазором минимум 1 м. Пересчитать размещение по доступной внутренней области квартала, а не просто увеличить box.
- Генератор принимает override конфигурации, детерминирован при одинаковых seed/config. Валидировать NaN, отрицательные размеры, min>max и невозможный план: понятная ошибка до удаления текущей сцены. При широких дорогах уменьшать footprint до доступной ячейки по явно описанному правилу; положительные минимальные размеры обязательны.
- Сохранить высоту каждого дома при прежнем seed: отдельный поток случайности для размеров или сохранение прежнего порядка выборок. Landmarks сохраняют существующую высоту.
- Render, статические коллайдеры, bounds occlusion и доступная область для движения используют один plan. Тротуары не накладываются на дорогу; основания не пересекаются между собой и с проезжей частью. Central plaza сохраняется.
- Запрос требует конфигов, не обязательно новых UI-слайдеров: не добавлять их без необходимости.
