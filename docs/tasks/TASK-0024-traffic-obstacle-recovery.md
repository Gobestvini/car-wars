## 4. Требуемое поведение

- Разделить законное ожидание приоритета/сигнала, движущуюся очередь и отсутствие прогресса из-за неподвижного препятствия. Детектор прогресса не зависит только от заданной скорости: сравнивать продвижение вдоль маршрута за окно времени.
- Предложение автора: после 3 с без продвижения проверить свободный коридор объезда. Состояния: ожидание, подготовка, объезд, возврат, ограниченный recovery; параметры времени/зазоров именованные, в метрах/секундах.
- Сначала свободная часть попутной полосы; встречная только если весь манёвр и возврат безопасны по прогнозу, отсутствуют запрещающие условия. Не объезжать красный сигнал, очередь у стоп-линии, не ехать по тротуару/сквозь дома и не пересекать занятый перекрёсток.
- Взаимный тупик разрешать устойчивым приоритетом ID: один уступает, другой маневрирует. Короткий задний ход допустим лишь при свободном пространстве сзади. Не телепортировать, не удалять машину и не снимать коллизии.
- При появлении встречного автомобиля отменять неподтверждённый манёвр; начатый завершать/прерывать безопасно без резкого переключения руления. Если пути нет, ожидать и периодически проверять заново.
- В debug() вывести причину остановки, время без прогресса и текущий манёвр; сбрасывать всё при reset, смене сети и удалении машины.
