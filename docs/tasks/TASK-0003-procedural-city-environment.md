## 1. Цель и запрос пользователя

Исходный запрос: «по созданию окружения похожего на город из разных былоков по которому будет интересно кататься и будет генерироваться автоматически».

Цель — заменить пустую демонстрационную площадку на автоматически создаваемое городское окружение из повторно используемых строительных блоков, где интересно свободно ездить на машине. Сейчас после загрузки автомобиля игрок видит плоскую пустую поверхность с координатной сеткой; после выполнения город должен формироваться автоматически при запуске и давать связную проезжаемую уличную сеть, разнообразные здания и ориентиры.

Предложение автора для первой версии: детерминированная генерация ограниченного района по seed из модульной сетки кварталов, дорог и наборов простых процедурных зданий. Не скачивать и не включать неуказанные ассеты или ресурсы GTA.

## 3. Область изменений

- Одна цель: реализовать первую готовую для игры версию автоматически создаваемой городской карты из переиспользуемых модулей.
- Предварительно ожидаемые изменения: `src/main.js`, один новый модуль генерации в `src/` (например, `src/city-generator.js`), при необходимости небольшой набор локальных процедурных материалов/геометрии; `README.md` и тесты генератора при наличии чисто модульной логики.
- Не включать загрузку реального географического города, сетевую генерацию, миссии, NPC, трафик, редактор карт, сохранение пользовательских миров или сторонние модели без согласования.
- Не менять поведение машины, камеры, джойстика, управления, следов шин и их настройки.
- Сохранить быстрый запуск, сброс машины, управление клавиатурой и указателем, режимы качества и работу на мобильном экране.
- Зафиксированное решение: здания и периметральная граница имеют статические физические коллизии. Отдельных приподнятых бордюров в первой версии нет; дорожные разметка и покрытие декоративны.
- Зафиксированное решение: компактный стилизованный старый европейский район, один детерминированный район с замкнутой физической границей.

## 4. Требуемое поведение

Целевой сценарий: открыть игру — после загрузки появляется небольшой визуально читаемый городской район; машина стартует на свободном участке дороги, пользователь может ездить по нескольким связанным улицам, поворачивать на перекрёстках и исследовать несколько отличающихся кварталов. При `R`/«Заново» сбрасывается автомобиль, а карта остаётся той же.

Критерии направления (точный масштаб/композицию определить перед реализацией):

1. Карта генерируется локально, без обязательного сетевого запроса; одинаковый seed даёт одинаковую раскладку. Seed может быть фиксирован для воспроизводимой первой версии.
2. Используются повторно применяемые строительные блоки: не менее нескольких вариантов фасадов/высот и хотя бы несколько визуальных ориентиров; монотонный массив одинаковых коробок не удовлетворяет цели.
3. Дороги образуют непрерывные проезжаемые маршруты с перекрёстками/поворотами и открытой стартовой зоной; здания не перекрывают старт и дорожное полотно.
4. Визуальная граница карты и поведение у её края понятны; при достижении края машина не должна бесконечно ехать по пустоте/сетке. Нужное поведение (граница, замкнутый район или расширяемый мир) требует решения до статуса `ready`.
5. Процедурные декорации не меняют телеметрию/силы машины. Если выбраны физические препятствия, их коллизии должны соответствовать видимым препятствиям и безопасно очищаться/создаваться вместе с картой.
6. На низком качестве сцена остаётся работоспособной; объём геометрии и теней ограничен, ресурсы можно освобождать при пересоздании мира.
