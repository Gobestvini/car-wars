## 4. Требуемое поведение

- Выбрать минимальную архитектуру разделения vehicle runtime, controllable role и spawn service. Предложение автора: гражданские и police используют общий CarSimulation/world/lifecycle, но независимые controllers. Сравнить минимальное расширение текущего runtime и небольшой extraction; выбрать один вариант с конкретными границами файлов.
- Описать API requestSpawn({role, position:{x,y,z}, yaw, targetId, options}) → структурированный результат created/pending/rejected с ID и причиной, либо равноценный контракт. Произвольные координаты — безопасная валидная поза в пределах карты, включая окраины/тротуар/площадь; не любое место внутри здания. Режим exact не молча переносит машину в центр; optional nearest-safe требует явного параметра.
- Указать регистрацию всех ролей в общей occupancy и safe insertion, владельца world.step, add/remove/reset/rebuild/dispose, поведение pending/cancel/invalid pose. Задача не требует превращать все поверхности в дорожную сеть.
- Описать pursuit → intercept/ram → maintain-block → recover: прямой путь только при свободном corridor, routing/локальное восстановление вокруг зданий; контакты физические. Намеренный контакт с target разрешён только полицейскому controller, spawn overlap запрещён для всех.
- Сравнение с игроком: идентичные базовые физические параметры и достаточный throttle на прямой, отсутствие гражданского target cap8/16. Задать воспроизводимый benchmark достижимой скорости/разгона; не обещать48 м/с из чтения ограничения сил.
- Зафиксировать LOD policy для pursuit: полиция, способная столкнуться с игроком, обязательно physical; лимит числа/дистанции и переход без ghost contact. Задать договор сигналов: предложение автора — преследующая полиция игнорирует red как evasion, сохраняет геометрию/контакты с городом и не отменяет безопасность гражданского AI.
- Предложенная приёмка остановки: на прямой с игроком без газа после физического тарана speed игрока<0.5 м/с≥2 с; против игрока с полным газом требовать повторяемый intercept/ram, не гарантированное мгновенное обездвиживание.
