## 4. Требуемое поведение

- Оба типа различимы в игровой камере: фонарь заметно выше урны, основание стоит на поверхности тротуара. Предложенные размеры: фонарь 3.5–4.5 м, урна 0.7–1 м, основание не шире свободного тротуара.
- Размещение воспроизводится по seed, распределено по городу с обеих сторон улиц, не попадает на асфальт, spawn-площадь, в здания, деревья, светофоры или damage obstacles. Проверять габариты, а не только центральную точку. Допустимый навес фонаря не перекрывает сигналы и обзор перекрёстка.
- Предложенные пределы: до 160 фонарей и 80 урн, фонари через ≥12 м, урны через ≥8 м; при нехватке места пропускать объект без бесконечного поиска. Числа — стартовый бюджет автора, уточнять по default городу и измерениям.
- Использовать общий материал и instancing по частям, ориентир ≤8 дополнительных batches в основном проходе. Low/high сохраняют оба типа; без покадрового пересоздания геометрии и материалов.
- Rebuild не дублирует props, dispose освобождает ресурсы. Переход free/follow не скрывает объекты неожиданно.
