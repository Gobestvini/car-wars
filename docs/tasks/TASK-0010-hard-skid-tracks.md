## 1. Цель и запрос пользователя

Запрос: «следы слишком рано появляются — только при самых жёстких поворотах или заносах». Обычная езда, разгон и мягкий поворот не оставляют полос. Сильный боковой занос или ручник на скорости оставляют непрерывные мягкие следы.

## 4. Требуемое поведение

После TASK-0008 измерить wheel.slip, lateral, longitudinal в обычном и резком повороте. Добавить чистый классификатор сильного заноса, не просто повысить START_SLIP. Начальная настройка автора: скорость в плоскости колеса ≥6 м/с, |lateral|≥2.2 м/с и |atan2(lateral,max(|longitudinal|,2.5))|≥0.28 рад. Для продолжения меньшие пороги ≥4 м/с, |lateral|≥1.5 м/с, угол ≥0.20 рад. Подтвердить условие старта 0.08 с; краткий провал до 0.12 с не разрывает полосу. Пороги уточнять по новой физике с отчётом.
Чистое demand/capacity из-за газа не должно включать следы. Ручник даёт след только при движении и фактическом скольжении, не на месте; если нужны данные handbrake, расширить интерфейс optional context без поломки существующих вызовов. Отсутствие контакта, detached, отключение чекбокса, reset, телепорт и смена направления завершают полосу немедленно и безопасно. Невалидные числа означают отсутствие нового следа. Счётчики задержек измеряются секундами fixed step, не количеством кадров. Не требовать следов от жёсткого поворота с идеальным сцеплением.
