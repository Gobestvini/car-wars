# Проверка исправления блюра и деревьев, 2026-10-08

Источник — настоящий WebGL в Codex In-app Browser на Windows. Воспроизведение: `npm run dev`, затем открыть `/tools/miniature-blur-regression.html`. Fixture использует производственные модули города и blur, Three.js 0.180, ACES с exposure1.22 и sRGB. Это статичный проверочный город с простым оранжевым кузовом, без симуляции NPC, GLTF машины, дыма/огня и динамических теней.

- `city-direct.png` и `city-blur.png`: одинаковые камера, город, материалы и свет, 1280×720/DPR1, high, сила0 и1. Видны связанные стволы, три формы крон и разные места посадки. Это кадры canvas, не макеты ImageGen.
- `blur-color-regression.json`: 640×360/DPR1, 390×844/DPR1.75 и844×390/DPR1.75; два quality и силы0/1/2. Семь цветовых плашек сравниваются через GPU readPixels, только внутри резкой области и вдали от границ геометрии. Максимальная разница RGB —0 во всех18 сочетаниях. Тест проверяет ошибку глобального затемнения/ACES/sRGB; намеренное смешение на периферии не должно давать равенство пикселей. Low при DPR1.75 — стресс-кейс, реальная игра ограничивает low доDPR1.
- Ресурсы fixture после прогрева и10 циклов resize/quality/strength: 33 geometries,3 textures,19 programs до/после. Это не профиль FPS на телефоне и не доказательство resource plateau для полной игры с reset/building fade/damage effects.
- Default город:320 деревьев,13 880 геометрических треугольников, четыре batches и два общих материала. Теневой проход добавляет повторную отрисовку; эта цифра не является суммарным числом треугольников игрового кадра.

Отдельно в настоящей игре проверены ввод0/2 в «Графика → Блюр краёв, ×», отключение/усиление эффекта и читаемость DOM. Новых shader/runtime ошибок в проверенных запусках не было. Физический телефон, длительная поездка и мобильные p95/p99 остаются непроверенными; TASK-0056/0057 сохраняют review.
