# Уличные модели — TASK-0075

2026-10-10. Процедурные low-poly модели из `src/city-street-props.js`; собственная геометрия проекта, без внешних ассетов и текстур. Единицы — метры, Y вверх, локальная +Z консоль фонаря направлена к дороге. Основание совпадает с y=0.155 тротуара.

Фонарь: шестигранное основание и опора, короткая консоль, прямоугольный плафон с отдельной светлой нижней линзой; высота 3.82 м, полный горизонтальный envelope radius=0.96 м. Урна: восьмигранный открытый корпус, толстый обод и тёмная внутренняя поверхность; высота 0.84 м, envelope radius=0.4 м. Декоративные модели, без физических тел, PointLight, анимаций и ночного режима. Матовая зелёная урна, тёмный металлический фонарь и тёплая линза сохраняются в обеих quality.

Default seed 20261005, дороги 15 м, тротуары 2 м: **160 фонарей, 80 урн**, 8 part batches, 4 shared материала, 22400 геометрических треугольников до shadow passes. `report.json` содержит фактическую разницу calls/triangles при выключении только новых batches в той же игровой сцене. Крупные планы каждой модели: `1440x900-*.png`, `390x844-*.png`. Общий вид: `overview.png`.

Placement использует существующий plan, реальный список деревьев и сигналов. Полный диск модели помещается в реальный прямой участок тротуара; невозможные угловые/узкие места пропускаются. Проверяются asphalt/plaza, здания, AABB повёрнутых damage obstacles, кроны деревьев, clearance сигналов и интервалы ≥12/8 м для однотипных объектов. Кандидаты ограничены числом рёбер и сортируются по seed; принятие прекращается при бюджетах. Нет покадрового поиска/пересоздания.

Тесты: seeds 1/20261005/928172, дороги 12/15/30 м, тротуары 0/0.3/0.8 м, полное отсутствие места, пересечения полных envelope, неизменность plan, реальные матрицы всех моделей и однократный dispose ресурсов за 10 перестроений. WebGL actual-game matrix включает low/high, follow/free, оба viewport и десять rebuild с quality/blur переключениями; resources стабилизируются.
