# Car Stars — low-poly машина игрока

Создана 2026-10-09 в Blender 5.2.2 LTS по [жёлтому turnaround-концепту](../../vehicles/2026-10-09/01-yellow-getaway.png) и концепту главного меню. Геометрия написана для проекта скриптом Blender Python; сторонняя модель не использовалась.

- [player-sedan.blend](player-sedan.blend) — редактируемый исходник, упакованный концепт, отдельные коллекции автомобиля и студии.
- [Игровой GLB](../../../../public/models/player-sedan.glb) — только кузов и четыре колеса, без камеры, света и студии.
- [Предпросмотр Blender](preview.png), [крупный план с игровым светом](verification/game-lighting-front.png), [вид сзади](verification/game-lighting-rear.png).
- [Статистика ассета](asset-report.json), [браузерный отчёт](verification/report.json).

## Геометрия и материалы

2 276 треугольников: кузов 1 524, каждое колесо 188. Пять мешей, один общий MeshStandard/PBR материал, цвета вершин, без текстур и UV. GLB 161 384 байта, около 158 КиБ. Пять отрисовок автомобиля в основном проходе; тени добавляют свои проходы. Обратные стороны отсекаются; нормали открытых стёкол и арок направлены наружу.

Кузов золотисто-жёлтый `#FFC12F`, тёмно-синие непрозрачные стёкла, серые бамперы и пороги, квадратные кремовые фары, красные задние фонари. Цвета записаны линейно из sRGB. Внешний вид Blender и Three.js отличается из-за света и tone mapping; игровой свет и ACES проверены отдельно. В GLB нет запечённых теней.

Все размеры — в метрах. В игре +X вправо, +Y вверх, +Z вперёд; в Blender +X вправо, +Z вверх, -Y вперёд. Origin кузова совпадает с существующим центром массы симуляции. Колёсная база 2.3 м, крепления X=±0.77 м, Z=±1.15 м, радиус колеса 0.45 м, ширина около 0.31 м. Колёса названы `wheel-front-left`, `wheel-front-right`, `wheel-rear-left`, `wheel-rear-right`; pivot каждого в его центре.

`body` — единая деформируемая сетка; на основных панелях оставлена редкая сетка для локальных вмятин. Стёкла и декоративные детали объединены с кузовом и деформируются вместе с ним. Это набор простых поверхностей, не герметичный CAD-кузов; его геометрия не используется как коллайдер.

## Интеграция

[player-model.js](../../../../src/player-model.js) приводит экспортированные меши к осям симуляции и проверяет наличие именованных частей. `main.js` загружает новый GLB в настоящем масштабе, подключает кузов к CarDeformation, а колёса — к существующим узлам подвески, руления, вращения и отрыва. Прежние дополнительные меши протектора убраны: шины уже входят в новый GLB.

Масса, силы шин, подвеска, точки крепления, физические коллайдеры и управление не менялись. Старый `sedan.glb` сохранён для исторических визуальных fixtures. Старое перекрашивание атласа больше не применяется к игроку: цвет берётся из новой модели.

Для будущей полиции использовать общий кузов и колёса, поменять цветовые области и добавить отдельную поперечную планку маяков поверх крыши. Этот шаг не выполнен: запрос ограничен автомобилем игрока. Дополнительный collider для обвесов не нужен без отдельной игровой причины.

## Воспроизведение и проверки

Пересборка из корня репозитория:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python tools/build-player-sedan.py
node --test tests/player-model.test.js tests/vehicle.test.js tests/car-deformation.test.js tests/car-damage.test.js tests/vehicle-repair.test.js
npm run build
```

После запуска Vite можно выполнить `tools/player-model-check.cjs`, задав `PLAYWRIGHT_MODULE` к установленному Playwright и `CARWARS_BASE_URL` к серверу. Проверяются настоящая загрузка GLB, повтор после ошибки, разгон, руление передних колёс, фронтальный удар с деформацией, отрыв одного колеса, сброс, портретный и альбомный экраны, отсутствие ошибок WebGL. Отдельно прошёл `tools/damage-effects-check.cjs`: дым, огонь, взрыв, reset и остановка терминального таймера при скрытой вкладке.

Результаты: 30/30 целевых тестов, сборка успешна, браузерные проверки успешны. Полный `npm test`: 282/283; существующий `tests/settings-defaults.test.js:81` ожидает дефолт зоны размытия 68, текущий дефолт 58. Это значение уже присутствовало до интеграции модели; в рамках моделирования тест или настройки размытия не менялись.

Проверка проведена на desktop Edge/SwiftShader. Физический телефон и его FPS не проверены; низкое число треугольников и отсутствие текстур сами по себе не доказывают бюджет всей игры.
