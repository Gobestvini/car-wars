# Машина игрока — модель по концепту

Обновлена 2026-10-10. [Сравнение «концепт — было — стало»](concept-review/comparison.png),
[семь игровых ракурсов](concept-review/all-views.png), [отчёт сверки](concept-review/README.md).

Исходник: [player-sedan.blend](player-sedan.blend), игровой экспорт:
`public/models/player-sedan.glb`, [атлас](sedan-atlas.png),
[статистика](asset-report.json), [превью Blender](preview.png).

Геометрия, UV и текстура авторские, созданы для CarWars в Blender 5.2.2 LTS
скриптами `tools/build-player-sedan.py` и `tools/sedan_texture.py` по существующему
жёлтому концепту `docs/art/vehicles/2026-10-09/01-yellow-getaway.png`.
Концепт и атлас упакованы в Blender. Сторонних моделей и текстур нет.

4140 треугольников (2876 кузов, по 316 на колесо), пять мешей, один общий материал
и один непрозрачный sRGB-атлас 1024×1024. PNG с mipmaps занимает около 5.33 МиБ
памяти GPU в RGBA8. GLB — 184920 байт. Четыре ореола фар используют один
дополнительный вызов отрисовки. Динамических источников света на машине нет.

Кузов шире и ниже прежней версии, с плавными фасками, наклонными капотом и
багажником, серой нижней отделкой и охватывающими углы бамперами. Текстура
содержит тонкие дверные швы с кромкой, золотые ручки, обрамление панелей,
три полосы радиатора, рамку номера, красные линзы с внутренними секциями,
рельеф колпаков и более мягкие переходы цвета пластика.

Окна непрозрачные. Их UV заданы аффинно в координатах панелей; трапециевидные
рамки и средняя стойка не изгибаются на диагонали треугольников. Окна имеют
высокую шероховатость, нормали соседних граней разделены, а фаски сглажены.
Краска получает небольшую компенсацию цвета и теней под игровым ACES-светом.
Зеркала по прежнему указанию пользователя убраны.

Передние фары светятся кремовым. Сзади только красные линзы: постоянные
габариты и усиление свечения при запросе заднего хода на малой скорости либо
фактическом движении назад. Интенсивность учитывает рисунок линзы,
светящиеся участки и ореолы следуют за деформацией.

Визуальный радиус колёс увеличен с 0.36 до 0.43 м для пропорций концепта,
ширина 0.26 м, 16 сегментов окружности. Арки имеют радиус 0.49 м и центр
на Y=-0.44 м; ограничение визуального сжатия подвески Y=-0.42 м.
Физический радиус 0.45 м, крепления X=±0.77 и Z=±1.15 м, подвеска, силы шин,
коллайдеры и управление сохранены. Визуальные колёса касаются той же земли.

Пересборка из корня проекта:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python tools/build-player-sedan.py
node --test tests/player-model.test.js tests/car-deformation.test.js tests/vehicle.test.js tests/car-damage.test.js tests/vehicle-repair.test.js
npm run build
```

Проверки: 33/33 целевых теста, production-сборка, семь игровых ракурсов,
браузерный сценарий загрузки и повтора после ошибки, разгона, руления,
заднего хода, столкновения с деформацией, отрыва колеса, сброса и мобильных
разрешений. [Браузерный отчёт](verification/report.json), ошибки JS/WebGL отсутствуют.
Проверено в Edge/SwiftShader на компьютере; FPS физического телефона не измерялся.
