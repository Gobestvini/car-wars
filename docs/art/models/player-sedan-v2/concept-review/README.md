# Сверка машины с концептом — 2026-10-10

[Сравнение основных ракурсов](comparison.png), [все семь ракурсов](all-views.png).
Колонки: концепт, машина до правок, машина после правок.

Снимки сделаны в настоящем приложении CarWars: передний и задний виды,
оба бока, сверху, передние и задние три четверти. Камера расположена относительно
текущего положения физической машины; используется игровой свет, материал,
тени, земля и модель. Трафик отключён только в проверке для воспроизводимости.
Ракурсы концепта вырезаны из существующего turnaround без перерисовки.

Обнаруженные расхождения и исправления:

- Короткий салон и крыша, чрезмерно длинный капот: длина крыши увеличена
  с 1.07 до 1.39 м, основание салона с 1.84 до 2.20 м, высота крыши снижена на 5 см.
- Капот и багажник были плоскими: добавлен наклон к внешним краям и фаски 3.5 см.
- Серый пояс был только между колёсами: теперь он продолжается на крыльях;
  бамперы стали выше и подходят к этому поясу.
- Арки остались под большие колёса: радиус отверстий уменьшен с 0.49 до 0.42 м,
  внутренние поверхности затемнены. Ограничение визуального хода подвески
  скорректировано на 2 см, проверен зазор при полном рулении и сжатии.
- Средние стойки окон были широкими жёлтыми: сделаны более тонкими графитовыми,
  в соответствии с концептом; швы дверей и ручки смещены под новый салон.
- Ниша номера ошибочно использовала полосы радиатора: теперь это тёмная сплошная
  область с рамкой. Сзади сохранены только красные светящиеся линзы.

Это приближение к концепту с учётом предыдущих указаний пользователя:
зеркала убраны, колёса меньше нарисованных, используются непрозрачные текстурные
окна. Колёсная база, физические крепления, ширина и длина коллайдера сохранены;
поэтому пропорции не являются точной копией сгенерированного рисунка.
Свет в игровой сцене отличается от студийного света концепта: жёлтая краска
на солнце светлее, в тени темнее. Студийные блики и мелкие детали концепта
не запекались в атлас. Автомобиль остаётся low-poly: 2060 треугольников,
пять мешей, один материал и одна текстура 512×512.

Воспроизведение после запуска Vite (Playwright доступен через PLAYWRIGHT_MODULE):

```powershell
node tools/review-player-concept.cjs before
node tools/review-player-concept.cjs after
python tools/build-player-comparison.py
```

Режим before загружает GLB из коммита 409da4b через перехват браузерного запроса,
не меняя файлы проекта. Камера тоже задаётся только через перехват ответа
тестовым скриптом; игровой интерфейс не получает дополнительных кнопок.

Проверки: 33 целевых теста, production-сборка, семь игровых ракурсов без ошибок
JS/WebGL, браузерный сценарий движения, заднего хода, повреждения, отрыва колеса
и сброса. Скриншоты и JSON-отчёты находятся рядом и в ../verification.
