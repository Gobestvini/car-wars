# Появление автомобилей

Storyboard зафиксирован 2026-10-12 до реализации TASK-0092.

| Кадр | Время | Вид |
| --- | --- | --- |
| Точка | 0–0.15 с | Тёплая светлая точка над дорогой, высота около 3 м. |
| Раскрытие | 0.15–0.45 с | Округлые кремовые клубы, автомобиль вырастает из центра без изменения yaw. |
| Посадка | 0.35–0.70 с | Машина плавно опускается с высоты 1.8 м; облако растекается. |
| Исчезновение | 0.55–0.90 с | Клубы расходятся в стороны и уходят в альфу; физика включается только после проверки свободного места. |

Палитра: кремовый #fff2dc и тёплый белый #fffaf0, без красного огня/серой копоти. Облако шириной около 4 м, мягкие края. Отличие от damage smoke: короткий светлый горизонтальный всплеск, а не тёмный восходящий столб.

High: 8 клубов, low: 4; один instanced draw, максимум 32 облака, слот игрока зарезервирован. Offscreen actor проходит ту же стадию безопасности, VFX скрывается. При насыщении — только рост/посадка машины, без расширения пула. Таймер по активному игровому времени. Занятое место удерживает стадию посадки; физический кузов до посадки отсутствует в solver, штатный footprint уже зарезервирован.
